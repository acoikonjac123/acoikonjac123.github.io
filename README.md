# Codeforces Submissions Fetch Tool

This project is a tool designed to retrieve submission records from Codeforces, utilizing an HTML+JS+CSS framework.

## Download

`git clone https://github.com/acoikonjac123/acoikonjac123.github.io.git`

Or click to download the zip file

## Usage

1. Run the index.html file (ignore this step in web mode)
2. Click the "Capture Data" button in the middle
3. Wait for a few minutes and you can view the results

## Precautions

- Do not refresh or click buttons frequently, as this may prevent normal information retrieval (due to interaction limits imposed by the Codeforces API)
